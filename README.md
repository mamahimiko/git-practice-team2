# Git Guide #

## Introduction ##
Welcome to our first team project - a website and guide for Git and Github.
This multi-page website is a collaboration project created by our team (Team 2) to showcase our collaboration skills, and understanding and knowledge of git and GitHub as new developers to other new developers. 

## Live Demo ##
 You can checkout our website here: <[link to website](https://mamahimiko.github.io/git-practice-team2/)>

## Project Structure ##
- **index.html** - Home page
- **about.html** - Page about the project and team
- **branching.html** - Page on branching
- **change.html** - Page on saving changes to a code
- **contact.html** - Page with a fill-out contact form
- **project.html** - Page about creating a project in GitHub.
- **cheetsheat.html** - Page for cheatsheets for developers use
- **global.css** - common styling for all pages of the website
- **project_page.css** - styling specific for the project page
- **about_us.css** - styling specific for the “About Us” page
- **typography.css** - styling for the fonts across the whole website
