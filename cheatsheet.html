Git Cheat Sheet Stickers!

A gift from the Git wizards! 🧙 🧙 🧙

Use these cheat sheets sticker to make working with Git and GitHub more fun!

Happy Hacking! 🚀

New Project

  • git init
  • git add . OR git add file-name
  • Create a repo on GitHub
  • git commit -m "message"
  • git remote add origin url-of-repo
  • git push -u origin branch-name
  • git push
  • git pull

Pull Changes from Remote

  • cd /path/to/your/local/repo
  • git branch OR git branch -a
  • git pull origin branch-name
  • git pull

This will update your local branch with the latest changes from the remote repository.

Creating a new branch

  • cd /path/to/your/local/repo
  • git branch OR git branch -a
  • git branch new-branch-name
  • git checkout -b new-branch-name
  • git branch
  • git push -u origin new-branch-name

git checkout -b new-branch-name creates a new branch and immediately switches to it!

Merging branches

  • cd /path/to/your/local/repo
  • git branch
  • git checkout branch-name
  • git pull origin branch-name
  • git merge branch-to-merge
  • git push -u origin new-branch-name
  • git log --oneline --graph --all

It can check that the merge worked

Reset your local branch

  • cd /path/to/your/local/repo
  • git branch
  • git checkout branch-name
  • git fetch origin
  • git reset --hard origin/develop

This will force your local branch to match the remote branch, discarding any local changes.

Pulling a new branch from GitHub

  • git fetch origin
  • git branch -r
  • git checkout branch-name
  • git checkout -b new-branch origin/new-branch

Create and switch to a local copy of that branch; Git automatically downloads the latest content of that remote branch into your new local branch.

Cloning Existing Project in GitHub

  • Copy the repository URL
  • cd /path/to/your/projects
  • git clone URL
  • cd repo-folder
  • git remote -v

This clones the repository to your local machine and lets you check the remote URL.
