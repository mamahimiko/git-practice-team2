Branches: Your Code’s Safety Net

Dobeen A

FUTUREGAMES student

Why Branching is important?

In Git, branching helps developers work on new features, bug fixes, or experiments without changing the main code.

It is important because

- Keeps the main code safe – You can try new things without breaking the main project.
- Helps group work – Many developers can work on different parts at the same time.
- Helps with testing – You can check each branch before adding it to the main code.
- Easy to combine – When the work is ready, you can merge it back into the main branch.

Make a new branch

step1:
git checkout -b branch_name
Make a new branch and switch to it.

step2: Add your changes
git add .
Get your changed files ready to save.

step3: Save your changes (commit)
git commit -m "message"
Save your changes in the branch.
Write a message to explain your work.

step4: Push the branch to GitHub
git push origin branch_name
Send your branch and changes to the online repository.
But the main branch is not changed yet.

step5: Merge the branch into main
git checkout main git merge branch_name
Put your branch changes into the main branch.
Now everyone can use your changes from the main branch.

step6:Delete the branch(local)
git branch -d branch_name
Delete the branch if you do not need it anymore.
Only delete branches that are already merged.

step:7
git push origin --delate name
To delete the branch on GitHub
